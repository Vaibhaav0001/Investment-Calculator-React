📈 Investment Calculator (React)
A simple yet powerful Investment Calculator built using React, JavaScript, HTML, and CSS. This tool helps users estimate the future value of their investments based on input parameters like initial amount, annual contribution, interest rate, and investment duration.

✨ Features
💵 Input fields for:

Initial investment amount

Annual contribution

Expected return rate (interest %)

Investment duration (years)

📊 Calculates and displays:
Year wise	Investment Value	
Interest(Year) per year
Total Interest	
Interest Capital per year


🔄 Real-time updates as inputs change

⚛️ Built with React for dynamic rendering and state management

📱 Responsive design with clean and user-friendly interface

🛠️ Technologies Used
React – Component-based UI and state management

JavaScript (ES6+) – Logic for calculations and interactivity

HTML – Page structure

CSS – Styling and layout

🚀 How to Run Locally
Clone the repository
Navigate to the project directory
Install dependencies:npm install
Start the development server:npm start/npm run dev
